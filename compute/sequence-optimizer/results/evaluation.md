# 순서 풀이기 평가

`python -m sequence_optimizer.evaluate`가 쓴다. 고정 입력은 `fixtures/snapshots.json`(시드 고정), 계획과 지금 규칙(부하표 Q3)의 비용은 백엔드가 쓴 `fixtures/baselines.json`이다. 비용 = 전환 분 + 늦어진 분 × 우선순위 가중치(urgent 4, high 2, normal 1, low 0.5). 풀이기는 OR-Tools CP-SAT, 한 사례 10초 제한, 지금 규칙의 순서를 시작 해로 준다. 시간 열은 기계마다 다르다.

|---|---:|---:|
| 계획 순서 | 49095.0 | |
| 지금 규칙(Q3) | 634252.5 | |
| 오늘의 최선(사례마다 계획과 Q3 중 싼 것) | 48195.0 | |
| 풀이기 | 33352.5 | 30.8% 적음 |

Q3는 전환 시간만 보고 계획 끝을 보지 않아, 이 비용으로는 계획 순서보다 크게 나쁠 수 있다. 그래서 풀이기는 Q3가 아니라 사례마다 계획과 Q3 중 싼 쪽(오늘의 최선)과 비교하고, 그 순서를 시작 해로 준다.

넣는 기준(ADR-039 결정 4: 오늘의 최선보다 합이 5% 이상 적고, 나빠진 사례 없음): **채움**. 나빠진 사례: 없음.
