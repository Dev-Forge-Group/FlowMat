# FlowMat 현재 기능 기준선

구현된 기능과 남은 범위를 정리한다. 상태를 바꿀 때는 근거 코드와 검증 결과를 함께 갱신한다. 아키텍처 결정은 [결정 인계](../architecture/decision-handoff.md)를 따른다.

- **IMPLEMENTED**: 코드와 대응 경로가 있다.
- **PARTIAL**: 일부 흐름만 구현됐다.
- **PLANNED**: 제안 단계다.

상태는 설계 범위의 구현 여부를 뜻한다. 운영 환경 검증 여부는 별도로 확인한다.

개발 DB(세션 DB 5434) 적용 현황: V83까지 2026-10-16, V87까지 2026-10-17에 복제본 리허설 뒤 적용했다. 아래 행의 "V52–V87 … 개발 DB 미적용"은 적용 전에 쓴 기록이다. V88–V94는 커밋(2026-10-18 `9500678`)과 복제본 리허설을 마쳤고 5434 적용은 사용자 결정 대기다. V95는 커밋 전이다.
2026-10-19 정정: V88–V101을 사용자 커밋(V88–V94 `9500678`, V95–V101 `86949f0`) 뒤 복제본 리허설을 거쳐 5434에 적용했다. 5434는 V101이다.
