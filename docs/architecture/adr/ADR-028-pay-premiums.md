# ADR-028: 연장·야간·휴일 할증

작성일: 2026-10-30

## 상태

**Accepted (2026-10-30). 로컬 구현 2hh(2026-10-30, 커밋 전, V126), 결정 10–12는 2hi(2026-10-30, 마이그레이션 없음), 결정 13–15는 2hj(2026-10-30, 커밋 전, V127), 결정 16–17은 2hk(2026-10-30, 커밋 전, V128), 결정 18–19는 2hl(2026-10-30, 커밋 전, V129), 결정 20–22는 2hm(2026-10-30, 커밋 전, V130), 결정 23–26은 2ho(2026-10-31, 커밋 전, V132), 결정 27은 2hp(2026-10-31, 마이그레이션 없음), 결정 28은 2hu(2026-10-31, 마이그레이션 없음).** [ADR-025](ADR-025-worker-labor-cost.md)와 [ADR-026](ADR-026-attendance.md)의 "결정하지 않은 것: 초과 근무·야간 할증"의 답이다. 사용자 선택 "초과 근무·야간 할증 단가 (Recommended)"(2026-10-30)가 할증을 출퇴근과 작업자 단가로 내고 배율·기준을 프로젝트 설정으로 두는 것을 정했다(결정 3·5). 나머지 세부는 사용자 사전 위임(2026-10-18 "구현 중 새 설계 선택 | 권장안으로 진행", 2026-10-24 "의사결정도 recommend 로 계속 알아서 밀고나가")에 따라 리드가 고른 권장안이다.

근거: [작업자 달력](../../domain/worker-calendar.md) LB19–LB22(단가·인건비), AT1–AT9(출퇴근), 프로젝트 휴일([설비 일정](../../domain/equipment-schedule.md) "휴일").

## 배경

| # | 지금 | 근거 |
|---|---|---|
| P1 | 인건비는 실행 작업자 시간의 분 × 그날 단가다. 그날 몇 분째인지, 몇 시였는지, 휴일인지는 보지 않는다 | LB21 |
| P2 | 실행 작업자 시간 줄에는 분과 기록한 날만 있고 시각이 없다 | LB1 |
| P3 | 출퇴근 줄에는 출근·퇴근 시각이 있고, 근무일은 출근한 날이다 | AT1, AT6 |
| P4 | 단가는 시작일이 있는 이력이고, 지난 날짜의 금액은 바뀌지 않는다 | ADR-025 결정 3·4 |

## 결정

| # | 결정 | 누가 |
|---|---|---|
| 1 | 할증 규칙은 **프로젝트마다 하나의 이력**이다. 한 줄 = 연장·야간·휴일 할증, 적용 시작일(프로젝트 날짜, 비우면 오늘), 사유, 누가, 언제. 단가와 같이 시작일은 오늘 이후만 받고, 같은 시작일로 다시 저장하면 새 줄이 이기며, 시작 전인 줄만 지운다(지운 줄도 남는다). 단가의 "처음부터"(ADR-025 결정 11)는 두지 않는다: 할증은 이미 정해진 금액을 바꾸기 때문이다 | 리드(사용자 선택 뒤 권장안) |
| 2 | **소유자만** 읽고 쓴다(금액 규칙, ADR-025 결정 1). 작업자 본인도 보지 않는다 | 리드(사용자 선택 뒤 권장안) |
| 3 | 할증은 셋이고 각각 선택이다. **연장** = 근무일 출퇴근 분 중 정한 분(1–1 440)을 넘는 분, **야간** = 정한 시각 창(프로젝트 시각, 끝이 시작보다 이르면 자정을 넘음) 안의 분, **휴일** = 프로젝트 휴일인 근무일의 모든 분. 각각 가산 %(1–500 정수). 모두 비운 규칙은 그 날짜부터 할증을 멈춘다 | 사용자 선택 "초과 근무·야간 할증 단가 (Recommended)"(2026-10-30) |
| 4 | 가산은 **겹치면 더한다**(야간 연장 = 연장 % + 야간 %, 휴일 연장 = 휴일 % + 연장 %). 근로기준법의 기본 방식이며, 배율은 프로젝트가 정한다 | 리드(사용자 선택 뒤 권장안) |
| 5 | **출퇴근으로 계산**한다(실행 작업자 시간에는 시각이 없다, P2). 읽을 때 계산하고 저장하지 않는다: 지급 분 = 출퇴근 분 + Σ(할증 분 × %/100, 소수 2자리), 금액 = 지급 분 × 그 근무일의 단가 / 60(소수 4자리 HALF_UP). 규칙과 단가는 그 근무일에 적용되던 것이다. 단가가 없으면 그날 금액은 미상이고 합계는 `costComplete=false` | 사용자 선택 "초과 근무·야간 할증 단가 (Recommended)"(2026-10-30) |
| 6 | 근무일과 분은 출퇴근 그대로(AT5·AT6): 출근한 날에 모두 세고 줄마다 분을 버린다. 야간 분도 줄마다 버린다. 열린 줄과 취소한 줄은 세지 않는다 | 리드(사용자 선택 뒤 권장안) |
| 7 | 새 소유자 전용 `GET·PUT /projects/{projectId}/labor-premiums`, `DELETE …/labor-premiums/{ruleId}`, `GET /projects/{projectId}/workers/{userId}/attendance-pay`(출퇴근과 같은 기간 규칙). 지금의 출퇴근·대조 응답은 그대로다(인건비는 결정 10) | 리드(사용자 선택 뒤 권장안) |
| 8 | 화면: 프로젝트 설정의 **Pay premiums**(소유자만), 작업자 카드 **Labor rate**의 **Pay with premiums** | 리드(사용자 선택 뒤 권장안) |
| 9 | 새 마이그레이션 V126 `labor_premium_rule` | 리드 |
| 10 | 실행·작업지시 인건비(LB21)의 기록마다 할증 포함 금액을 낸다: 금액 × 그 사람의 그날(단가를 고르는 날, LB21) 지급 분 ÷ 출퇴근 분. 그날의 할증을 그날 기록한 모든 작업자 시간에 고르게 나눈다(기록에는 시각이 없어 어느 실행이 연장·야간이었는지 모른다). 그날 출퇴근이 없으면 기본 금액 그대로이고 할증을 모른다고 표시한다. 기본 금액은 그대로 둔다 | 사용자 선택 "실행·작업지시 인건비에 할증 붙이기 (Recommended)"(2026-10-30) |
| 11 | 응답: 기록마다 `premiumFactor`(지급 ÷ 출퇴근, 소수 4자리, 출퇴근이 없으면 null)·`premiumCost`, 사람·합계·작업지시에 `premiumCost`·`premiumsComplete`. 생산 쪽은 workforce 새 공개 API `WorkerPayQuery.paidDays`(근무일마다 출퇴근 분과 지급 분, 결정 5·6 그대로)로 읽는다. 새 마이그레이션 없음 | 리드(사용자 선택 뒤 권장안) |
| 12 | 화면: 실행 상세 **Labor cost**와 작업지시 **Labor cost of the runs**에, 할증이 금액을 바꿀 때만 ` · with pay premiums 162`(출퇴근이 없는 날이 있으면 ` (days without attendance at the rate)`), 사람 줄도 같이 | 리드(사용자 선택 뒤 권장안) |
| 13 | **주 단위 연장**: 규칙에 주 연장 기준 분(1–10 080)과 가산 %(1–500, 함께), 주의 시작 요일(1 월–7 일, 비우면 월). 주 연장이 없으면 시작 요일도 없다 | 사용자 선택 "주 단위 연장(주 40시간) (Recommended)"(2026-10-30) |
| 14 | 계산: 근무일마다 보통 분 = 출퇴근 분 − 그날 연장 분. 그날의 주(그날 규칙의 시작 요일부터 그날까지) 보통 분 누계가 기준을 넘은 만큼에서 앞날들이 이미 넘은 만큼을 뺀 것이 그날의 주 연장 분이다. 그래서 하루 연장과 같은 분을 두 번 세지 않는다. 가산은 다른 가산과 더한다(결정 4). 읽는 범위 앞의 같은 주 날도 센다. 날마다 그날의 규칙을 쓴다(주 중간에 규칙이 바뀌면 그날부터 새 기준) | 리드(사용자 선택 뒤 권장안) |

| 17 | 응답 `days[].restDayHoliday`와 규칙 줄 `restDaysAsHolidays`, 화면 **Rest days count as holidays**와 줄 `holidays and rest days +100%`·`rest day`. 일정은 그런 규칙이 범위에 있을 때만 읽는다. 새 마이그레이션 V128(`labor_premium_rule.rest_days_as_holidays_yn`) | 리드(사용자 선택 뒤 권장안) |

| 24 | 시각이 있는 기록의 할증 포함 금액은 그 분마다 그 시각에 걸린 할증을 더한다. 그날 출퇴근의 분은 시계 순서로 정규, 주 연장(결정 14), 하루 또는 휴일 연장(결정 3, 18)이고, 야간 창 안은 야간 %, 휴일과 휴일로 치는 쉬는 날은 휴일 %가 더해진다. 출퇴근 밖 시간은 단가 그대로이고 할증을 모른다고 표시한다. 비율은 그 시각의 지급 분 ÷ 그 시각의 분이고, 기록한 분이 더 적으면 고르게 적용한다. 단가 날짜는 시작한 프로젝트 날짜다 | 리드(사용자 선택 뒤 권장안) |

## 결과

- 좋은 점: 소유자가 출퇴근으로 연장·야간·휴일을 반영한 지급을 근무일마다 본다. 정한 규칙은 지난 날짜를 바꾸지 않는다.
