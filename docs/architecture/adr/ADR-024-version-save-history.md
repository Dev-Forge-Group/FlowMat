# ADR-024: 판의 저장 이력

작성일: 2026-10-19

## 상태

**Accepted (2026-10-19). 로컬 구현 2fc(2026-10-19, V101, `86949f0`에서 커밋).** [ADR-017](ADR-017-version-reasons.md)이 남긴 "판의 저장 이력(한 판을 여러 번 고친 기록)을 따로 남길지"를 골랐다(사용자 지시 "어떤기능이던 지금 구현된 기능과 연관된것 부터 처리해", 2026-10-18). 세부는 사용자 사전 위임(2026-10-18, "구현 중 새 설계 선택 | 권장안으로 진행")에 따라 리드가 고른 권장안이다.

**확장 Accepted (2026-10-23). 로컬 구현 2fe(V102, 2026-10-25 `398de46`에서 커밋).** 사용자 계획 "9. ADR-024 확장 per-date shift day off downtime history"(2026-10-19)에 따라 "결정하지 않은 것"의 날짜별 교대·쉬는 날·정지 이력을 더했다(결정 7–12). 세부는 같은 사전 위임의 권장안이다.

근거: [ADR-013](ADR-013-rota-history.md)(근무표 판), [ADR-014](ADR-014-equipment-calendar-history.md)(설비 달력 판), [ADR-017](ADR-017-version-reasons.md)(판 사유), [작업자 달력](../../domain/worker-calendar.md) WC55–WC64, [설비 일정](../../domain/equipment-schedule.md) CV1–CV11.

## 배경

판은 마지막 저장만 남는다. 같은 날짜로 다시 저장하면 앞의 교대·사유·저장한 사람이 사라지고, 시작 전에 지운 판은 흔적이 없다.

## 결정

| # | 결정 | 누가 |

| 1 | 작업자 근무표 판과 설비 달력 판을 저장하거나 지울 때마다 이력 한 줄을 남긴다: 판, 시작일, `saved`·`removed`, 사유, 그때의 교대(작업자는 순환 근무표도), 누가, 언제. 저장과 같은 트랜잭션이다 | 사용자 사전 위임(2026-10-18) |

## 결정하지 않은 것

- 날짜별 교대·쉬는 날·정지의 저장 이력. 결정 7–12에서 정했다(2026-10-23, 2fe)
- 이력을 얼마나 오래 둘지(지금은 지우지 않는다)

## 결과

- 좋은 점: 근무표·설비 달력을 누가 언제 어떻게 바꿨는지, 지운 판이 무엇이었는지 남는다.
- 위험: V101이 V95–V100 뒤에 붙는다(2026-10-19 `86949f0`에서 함께 커밋). 새 표 둘만 만든다. 저장마다 줄이 늘어난다(조회는 100줄까지).
- 확장(2fe): 날짜별 교대·쉬는 날·설비 정지도 누가 언제 무엇을 바꿨는지, 지운 것이 무엇이었는지 남는다. 위험: V102(2026-10-25 `398de46`에서 커밋)는 새 표 둘만 만든다. 범위 저장 한 번이 줄 하나라 한 줄의 날짜 목록이 길 수 있다(범위는 62일까지, 복사는 보낸 쪽의 날짜 수만큼).
