# ADR-047: 제품 설명으로 공정 초안 (첫 AI 결정 ①)

작성일: 2026-11-24

## 상태

**Accepted (2026-11-24).** [로드맵](../../status/ROADMAP-2026-11-23.md) §5의 7번 ①이다: "만들 제품을 설명하면 공정도와 재료 초안이 나온다(초보자의 입구)". 세부는 2026-10-24 위임에 따라 권장안이다. 사용자 지시(11-24 "ㄱ")로 시작했다. 어떤 서비스와 키를 쓸지는 사용자가 정하지 않았으므로, **기본은 꺼져 있다.** 켜는 것은 키를 정하는 사람이 한다.

## 결정

1. **흐름.** 홈의 "설명으로 시작"에 무엇을 어떻게 만드는지 적는다.
   - 서버가 초안을 만들고 검사해서 돌려준다. 저장하지 않는다.
   - 사람이 읽고 "이 초안으로 만들기"를 누르면, 견본과 같은 빌더(`buildSample`)가 공개 API로 새 프로젝트에 품목·공정·포트·연결을 만들고 게시한다.
   - 재고·설비는 넣지 않는다. 공장이 자기 것을 넣는다.
2. **모델.** Claude Messages API를 공식 Java SDK(`com.anthropic:anthropic-java`)로 부른다(`ClaudeProcessDraftModel`).
   - 모델은 `claude-opus-5-5`이고 `APP_AI_PROCESS_DRAFT_MODEL`로 바꿀 수 있다.
   - 답은 구조화 출력(`outputConfig(ProcessDraftResponse.class)`)이다. 스키마는 응답 레코드에서 나온다.
   - 생각은 기본(adaptive), effort도 기본(medium)이다. 시간 제한은 2분이다.
   - 모델이 거절하면(`stop_reason: refusal`) 502와 "견본으로 시작" 안내를 낸다.
   - 서버 쪽 자동 대체(`fallbacks`)는 넣지 않았다. Java SDK의 설정 방법이 문서에 없다. 초안은 실패해도 견본으로 시작할 수 있다.
   - **켜는 조건:** `APP_AI_PROCESS_DRAFT_ENABLED=true`이고 `ANTHROPIC_API_KEY`가 있어야 한다(`ProcessDraftConfigured`). 아니면 모델 빈이 없고 API는 503이다.
   - 키는 비밀값이라 저장소에 넣지 않고 로그에 남기지 않는다.
   - SDK는 Kotlin으로 돈다. Spring Boot 4.1.3이 관리하는 Kotlin 2.3.21은 OWASP 검사에서 치명(CVE-2026-53914)이 나와서, `build.gradle`에서 2.4.21로 고정했다(2026-11-24).
3. **검사(`ProcessDraftCheck`).** 모델의 답은 사람에게 보이기 전에 검사한다. 하나라도 어기면 502다.
   - 크기: 품목 2–30개, 단계 1–12개
   - 이름: 길이 제한
   - 품목 코드: 대문자·숫자·대시
   - 종류: material·semi·product
   - 단위: kg, g, t, l, ml, ea, m, cm, mm. 단위 표에 있는 것만이라 공개 API가 받는다.
   - 수량: 0 초과 100만 이하
   - 단계 순서: 단계는 재료와 앞 단계가 만든 것만 쓴다. 고리가 생기지 않는다.
   - 만들기: 중간품·제품은 꼭 한 단계가 만든다. 재료는 만들지 않는다.
   - 목표: 제품이어야 한다.
4. **남용 막기.** API(`POST /process-drafts`)의 조건이다.
   - 로그인해야 한다.
   - 사람마다 시간당 10번까지다(`APP_AI_PROCESS_DRAFT_HOURLY_LIMIT`, Redis). 넘으면 429다.
   - 서버 전체로 하루(UTC) 30번까지다(`APP_AI_PROCESS_DRAFT_DAILY_LIMIT`, 2026-11-24). 비용 상한이다. 검사에 걸린 답도 센다. 넘으면 429다.
   - 설명은 2,000자까지다.
5. **개인정보.**
   - 켜면 적은 설명이 Anthropic의 API로 간다(국외 이전·위탁, [개인정보 목록](../../operations/personal-data.md) P7). 화면은 그 사실을 적는다.
   - 설명 말고는 보내지 않는다. 프로젝트 자료, 이름, 이메일은 가지 않는다.
6. **AI 없이도.** 꺼진 서버에서는 API가 503이고(로드맵 §5의 7번 "둘 다 실패하면 AI 없이도 쓸 수 있게 둔다"), 홈은 "설명으로 시작" 카드를 아예 보이지 않는다. 홈이 `GET /process-drafts/availability`(`{available}`)로 먼저 묻는다(2026-11-28). 처음 쓰는 사람에게 실패할 수밖에 없는 단추를 내밀지 않는다.

## 확인

- `ProcessDraftCheckTest`: 올바른 초안은 통과한다. 단계 순서 어김, 모르는 단위, 제품이 아닌 목표는 걸린다.
- `ClaudeProcessDraftModelTest`: 요청(모델, 메시지 하나, 구조화 출력)이 네트워크 없이 만들어진다.
- `ProcessDraftIntegrationTest`: 꺼진 서버다. 로그인 없으면 401, 빈 설명은 400, 나머지는 503이다.
- `ProcessDraftStubIntegrationTest`: 대신 답하는 모델로 본다. 검사를 통과한 초안은 200, 검사에 걸리는 초안은 502, 한 사람의 시간 한도나 서버의 하루 한도를 넘으면 429다.
- **켜기 전의 평가:** [평가 설계](../../domain/process-draft-evaluation.md). 운영 기본 켜기는 보류이고, 호출과 과금은 따로 승인받는다(2026-11-24 사용자 결정).
- 모의 E2E `start-from-description.spec.ts`: 초안이 보이고, 만들기 전에는 쓰는 것이 없다. 만들면 연결과 시간 요건이 생긴다. 꺼진 서버에서는 안내가 뜬다.
- **실제 모델로 돌려 보는 것은 키가 생긴 뒤에 한다.** 비용이 드는 호출이라 사람이 정한다.

## 하지 않은 것

- 초안 고쳐 쓰기(대화), 여러 안 중 고르기
- 설비·인력·손실의 초안
- 평가 세트(좋은 초안의 기준과 점수). 파일럿 설명이 모이면 만든다.
