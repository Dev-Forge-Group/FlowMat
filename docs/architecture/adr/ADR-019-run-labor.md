# ADR-019: 실행 작업자 시간

작성일: 2026-10-19

## 상태

**Accepted (2026-10-19). 로컬 구현 2ex(2026-10-19, V96, `86949f0`에서 커밋).** 사용자 지시("어떤기능이던 지금 구현된 기능과 연관된것 부터 처리해", 2026-10-18)에 따라 [ADR-013](ADR-013-rota-history.md)의 "근무 시간 기록(실적)과의 비교", [ADR-016](ADR-016-crew-aware-delay.md)의 "실제로 일한 사람(실적)과 견주는 것", [작업자 달력](../../domain/worker-calendar.md) WC10·WC16이 범위 밖으로 둔 실적 기록을 골랐다. 세부는 사용자 사전 위임(2026-10-18, "구현 중 새 설계 선택 | 권장안으로 진행")에 따라 리드가 고른 권장안이다.

근거: [작업자 달력](../../domain/worker-calendar.md) WC11–WC16(작업지시 인력), WC36(몫), LB1–LB8. 같은 모양의 [설비 가동 시간](../../domain/equipment-setup-cost.md) ER1–ER9.

## 결정

| # | 결정 | 누가 |
|---|---|---|
| 1 | 실행마다 누가 몇 분 일했는지 기록한다. 실행 × 사람 × 분(1–10 080)과 메모. 설비 가동 시간(ER1–ER4)처럼 열린 실행에서만 기록하고, 지우지 않고 사유와 함께 취소한다. 같은 `requestId`의 재송신은 현재 상태를 돌려준다 | 사용자 사전 위임(2026-10-18) |
| 2 | 기록되는 사람은 그 프로젝트의 소유자나 구성원이다. 작업지시 인력에 없어도 된다(도우러 온 사람). 기록은 Project write 권한이 있는 사람이 하고, `userId`를 빼면 부른 사람이다 | 사용자 사전 위임(2026-10-18) |
| 3 | 금액은 없다. 작업자 단가가 없고, 재료비·단위 원가에도 더하지 않는다 | 사용자 사전 위임(2026-10-18) |
| 4 | 제안은 인력에게만 한다. 실행 시작부터 마감(열려 있으면 지금)까지 그 사람의 근무 시간 × 몫 − 이미 센 분. 교대가 없으면 실행 시간 × 몫 | 사용자 사전 위임(2026-10-18) |
| 5 | 대비: 작업지시 Readiness에 사람마다 계획(계획 기간 안 근무 시간 × 몫, 인력 고르기가 보여 주는 시간과 같은 셈) 대 실제 실행(시뮬레이션·테스트 제외)의 기록 | 사용자 사전 위임(2026-10-18) |
| 6 | 분은 정확한 정수만 받는다(2.5 거절, 1.0과 정수 문자열은 받음). 공용 `global/util/WholeNumberDeserializer`를 두고, 설비 요일 읽기(설비 일정 S7)도 이것을 물려받는다 | 사용자 사전 위임(2026-10-18) |
| 7 | 새 마이그레이션 V96 `production_run_labor`. V75 설비 가동 시간과 같은 모양이고 단가 열은 없다 | 사용자 사전 위임(2026-10-18) |

- 작업자 단가와 인건비. [ADR-025](ADR-025-worker-labor-cost.md)에서 정했다(2026-10-23, 로컬 구현 2ff)

- 생산 단계(2el)별 작업자 시간. [ADR-021](ADR-021-labor-step.md)에서 정했다(2026-10-19)

## 결과

- 좋은 점: 인력 계획(몫과 교대)이 실제와 얼마나 맞았는지 작업지시마다 보인다. 설비 가동 시간과 같은 방식이라 API와 화면이 익숙하다.
- 위험: V96이 V95 뒤에 붙는다(2026-10-19 `86949f0`에서 함께 커밋). 새 표만 만들므로 기존 행은 그대로다.
